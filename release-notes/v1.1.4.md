# WorldAreaReset v1.1.4

## English

WorldAreaReset 1.1.4 introduces a clearer official product description for PvP server administrators.

### Official positioning

- WorldAreaReset is designed for scheduled terrain maintenance in administrator-defined free-for-all PvP zones.
- Automatic and administrator-triggered cleanup remove non-allowlisted blocks and non-player entities inside the configured cuboid.
- The cleanup helps heavily used combat areas remain clean and reusable without claiming to regenerate the original terrain.
- WorldAreaReset does not create regions, enable PvP, or manage combat permissions; configure those rules in a dedicated region or PvP-management system.
- Plugin behavior, configuration values, messages, and cleanup scheduling remain unchanged in this release.

The README, administrator guide, plugin metadata, and GitHub project description now use the same official positioning.

## 中文

WorldAreaReset 1.1.4 为 PvP 服务器管理员提供更清晰一致的官方产品说明。

### 官方定位

- WorldAreaReset 专为管理员指定的自由 PvP 区域提供定时地形维护。
- 自动清理与管理员手动清理都会移除配置长方体范围内的非白名单方块和非玩家实体。
- 清理流程用于让频繁使用的战斗区域保持整洁并可继续使用，但不会宣称能够重新生成原始地形。
- WorldAreaReset 不负责创建区域、开启 PvP 或管理战斗权限；这些规则应由专用区域或 PvP 管理系统配置。
- 本次发布不改变插件逻辑、配置参数、消息文本或清理排程。

README、管理员手册、插件元数据与 GitHub 项目介绍现已采用一致的官方定位。
