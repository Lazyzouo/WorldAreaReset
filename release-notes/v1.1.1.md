# WorldAreaReset v1.1.1

## English

WorldAreaReset 1.1.1 restores complete editable messages to the official configuration templates and defines the project's tested compatibility range.

### Compatibility

- Tested and supported server: Paper/Folia 1.21.11 only.
- Required runtime: Java 21 or newer.
- Other Minecraft versions, Spigot, CraftBukkit, Purpur, and hybrid/modded servers are untested and receive no compatibility guarantee.

### Configuration

- Notifications, broadcasts, help menus, and updater messages are restored under `messages.en_US.*` or `messages.zh_CN.*`.
- Switching `language` selects the matching message namespace without cross-language overrides.
- Legacy flat `messages.*` customizations remain compatible.
- Server-specific world, boundaries, interval, allowlist, and update switches retain safe official presets.

### Important

Automatic cleanup remains disabled in official defaults. Back up the world before enabling cleanup. Large or unloaded areas may still cause synchronous chunk loads and Folia Watchdog warnings.

## 中文

WorldAreaReset 1.1.1 在官方配置模板中恢复完整可编辑消息，并明确项目的测试兼容范围。

### 版本限制

- 仅测试并支持 Paper/Folia 1.21.11。
- 需要 Java 21 或更高版本。
- 其他 Minecraft 版本、Spigot、CraftBukkit、Purpur 及混合/模组服务端均未测试，不提供兼容保证。

### 配置调整

- 通知、广播、帮助菜单和更新提示已恢复至 `messages.en_US.*` 或 `messages.zh_CN.*`。
- 修改 `language` 会选择对应消息命名空间，不会被另一语言覆盖。
- 继续兼容旧版扁平 `messages.*` 自定义项。
- 世界、坐标范围、周期、白名单和更新开关等服务器专用参数继续采用安全的官方预设。

### 重要说明

官方默认配置仍关闭自动清理。启用前必须备份世界；大范围或未加载区域仍可能同步加载区块并触发 Folia Watchdog。
