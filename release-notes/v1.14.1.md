# WorldAreaReset 1.14.1

## English

- Color the `/war cleanup` help command with the KitLoader palette and split plugin metadata into name, author, and version rows.
- Keep cleanup and restoration schedule rows visible when disabled, showing `not scheduled` until enabled.
- Display live cleanup and restoration countdowns down to seconds using the configured maximum unit.
- Use the documented single severity colors for updater and startup console notices instead of gradients.
- Migrate format 23 configurations to the format 24 help metadata layout.

## 中文

- 使用 KitLoader 调色板为帮助菜单中的 `/war cleanup` 指令上色，并将插件名称、作者和版本拆分为三行。
- 定时清理或热恢复关闭时仍显示对应状态行，未启用时显示“未排程”。
- 按配置最大单位显示清理与热恢复倒计时，并精确到秒。
- 更新器和启动后台提示使用文档规定的单色状态色，不再使用渐变色。
- 将格式 23 配置迁移到格式 24 帮助菜单元数据布局。
