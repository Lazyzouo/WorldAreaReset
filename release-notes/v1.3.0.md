# WorldAreaReset v1.3.0

## English

WorldAreaReset 1.3.0 introduces safe automatic configuration migration. Server owners can install future JAR updates without deleting `plugins/WorldAreaReset/config.yml` or re-entering existing settings.

### Downloads

- English defaults: `WorldAreaReset-1.3.0-en.us.jar`
- Simplified Chinese defaults: `WorldAreaReset-1.3.0-zh.cn.jar`

Release automation uploads exactly these two files from `build/libs/` under their original names.

### Automatic configuration migration

- Parses the live configuration and bundled defaults as structured YAML during startup.
- Adds only missing paths; existing values, custom messages, unknown keys, `false`, zero, empty strings/lists, selected language, and parsed comments remain unchanged.
- Updates customized `lang/en_US.yml` and `lang/zh_CN.yml` with the same missing-key rule.
- Keeps bundled language defaults attached in memory so missing messages remain available even when a language-file merge is blocked.
- Advances `config_version` from `3` to `4` only after a compatible merge.
- Retains deprecated and unknown keys instead of guessing that they are safe to delete.

### Write safety and recovery

- Copies the exact original bytes to `<file>.before-v1.3.0.bak` before changing a file.
- Saves and flushes the merged YAML through a temporary file in the same directory.
- Replaces the live file atomically when supported by the filesystem, with a safe same-directory fallback.
- Never overwrites malformed YAML or incompatible section/value types.
- Stops plugin startup before cleanup scheduling if the main configuration cannot be migrated safely.

### Verification and compatibility

- Includes automated coverage for value preservation, custom keys, comments, empty lists, backups, idempotence, conflicts, malformed YAML, and language-file migration.
- Tested and supported only on Paper/Folia 1.21.11 with Java 21.
- Automatic cleanup remains disabled in official defaults.
- Cleanup behavior, scheduling, updater networking, in-game formatting, and the console banner are unchanged.
- The permanent GitHub Release/tag retention floor remains `v1.2.5`; both `v1.2.5` and `v1.3.0` are retained.

## 中文

WorldAreaReset 1.3.0 新增安全的配置自动迁移。服主安装今后的新版 JAR 时，不再需要删除 `plugins/WorldAreaReset/config.yml`，也不需要重新填写已有设置。

### 下载

- 英文默认包：`WorldAreaReset-1.3.0-en.us.jar`
- 简体中文默认包：`WorldAreaReset-1.3.0-zh.cn.jar`

Release 自动化只会从 `build/libs/` 原名上传这两个文件。

### 配置自动迁移

- 启动时把服务器实际配置与内置默认配置作为结构化 YAML 解析。
- 只补充缺失路径；已有值、自定义消息、未知键、`false`、零值、空字符串/列表、语言选择和已解析注释均保持不变。
- 自定义的 `lang/en_US.yml` 与 `lang/zh_CN.yml` 使用相同的缺失键合并规则。
- 在内存中继续挂载内置语言默认值，即使语言文件迁移受阻，也能提供缺失消息。
- 只有兼容合并成功后，才将 `config_version` 从 `3` 更新为 `4`。
- 废弃键和未知键会被保留，不会猜测并自动删除。

### 写入安全与恢复

- 修改文件前，将原始字节精确备份为 `<文件>.before-v1.3.0.bak`。
- 合并后的 YAML 会先写入并刷新到同目录临时文件。
- 文件系统支持时原子替换正式文件，否则使用安全的同目录替换方式。
- YAML 损坏或配置节/值类型不兼容时绝不会覆盖原文件。
- 主配置无法安全迁移时，会在创建清理排程前停止插件启动。

### 验证与兼容性

- 自动测试覆盖参数保留、自定义键、注释、空列表、备份、幂等、冲突、损坏 YAML 及语言文件迁移。
- 仅测试并支持 Paper/Folia 1.21.11 与 Java 21。
- 官方默认配置继续关闭自动清理。
- 清理行为、排程、更新器联网、游戏内格式及后台横幅均未更改。
- GitHub Release/标签的永久保留起点仍为 `v1.2.5`，因此 `v1.2.5` 与 `v1.3.0` 都会保留。
