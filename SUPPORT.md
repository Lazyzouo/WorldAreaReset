# Support / 使用支持

## English

Before opening an issue:

1. Confirm Java 21 or newer and Paper/Folia 1.21.11. Other server versions and implementations are outside the supported compatibility range.
2. Test the latest WorldAreaReset release.
3. Read `README.md` and `WorldAreaReset.md`.
4. Back up the world and reproduce with the smallest cleanup area possible.
5. Remove secrets, addresses, player identifiers, and unrelated logs.

Bug reports should include the plugin version, exact server build, relevant configuration with private data removed, full error stack, expected result, and reproduction steps.

Use GitHub Issues for reproducible bugs and feature proposals. General server administration or unrelated plugin support is outside this project's scope.

## 中文

创建 Issue 前请：

1. 确认使用 Java 21 或更高版本以及 Paper/Folia 1.21.11；其他服务端版本与实现不在兼容支持范围内。
2. 使用最新 WorldAreaReset Release 测试。
3. 阅读 `README.md` 与 `WorldAreaReset.md`。
4. 备份世界，并用尽可能小的范围复现。
5. 删除密钥、地址、玩家标识和无关日志。

错误报告应包含插件版本、准确服务端构建、移除隐私后的相关配置、完整错误堆栈、预期结果和复现步骤。

可复现错误与功能建议请使用 GitHub Issues。通用服务器管理或无关插件问题不属于本项目支持范围。
