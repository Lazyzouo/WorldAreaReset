# WorldAreaReset v1.2.1

## English

WorldAreaReset 1.2.1 standardizes bold player-facing text and aligns divider-based cleanup broadcasts around their `✦` marker.

### Downloads

- English defaults: `WorldAreaReset-1.2.1-en.us.jar`
- Simplified Chinese defaults: `WorldAreaReset-1.2.1-zh.cn.jar`

Release automation uploads exactly these two files from `build/libs/` under their original names.

### In-game presentation

- Every plugin message displayed in-game is forced bold at runtime.
- Configured legacy colors, hex colors, and reset codes preserve the bold presentation.
- Cleanup warning and completion broadcasts center every content line against the divider `✦`.
- Each line of a multiline cleanup broadcast repeats the configured plugin prefix.
- Help menus are bold but retain their configured spacing and are not automatically centered.

### Compatibility and safety

- Tested and supported only on Paper/Folia 1.21.11 with Java 21.
- Automatic cleanup remains disabled in official defaults.
- Message text, colors, configuration values, comments, cleanup scheduling, and cleanup behavior are unchanged.
- Back up the target world before enabling cleanup.

## 中文

WorldAreaReset 1.2.1 统一了插件游戏内文本的粗体显示，并让带分割线的清理广播按照 `✦` 标记居中对齐。

### 下载

- 英文默认包：`WorldAreaReset-1.2.1-en.us.jar`
- 简体中文默认包：`WorldAreaReset-1.2.1-zh.cn.jar`

Release 自动化只会从 `build/libs/` 原名上传这两个文件。

### 游戏内显示

- 插件在游戏内显示的全部文本都会在运行时强制设为粗体。
- 已配置的旧式颜色码、十六进制颜色和重置码不会中断粗体效果。
- 清理警告与完成广播的每行正文都会按照分割线的 `✦` 居中。
- 多行清理广播的每一行都会重复已配置的插件前缀。
- 帮助菜单仍为粗体，但保留配置中的原有排版，不会自动居中。

### 兼容与安全

- 仅测试并支持 Paper/Folia 1.21.11 与 Java 21。
- 官方默认配置继续关闭自动清理。
- 消息文本、颜色、配置值、注释、清理排程与清理行为均未更改。
- 启用清理前必须备份目标世界。
