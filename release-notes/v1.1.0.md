# WorldAreaReset v1.1.0

## English

WorldAreaReset 1.1.0 is the first public bilingual release. It adds Simplified Chinese and English modes, safe public defaults, GitHub update checks, optional automatic update downloads, and a redesigned startup banner.

### Highlights

- Select `zh_CN` or `en_US` with the `language` setting.
- Use the English-default or Simplified-Chinese-default release JAR.
- Check official GitHub Releases automatically at server startup.
- Download a verified release JAR into Bukkit's update directory when a newer version exists.
- Receive a direct GitHub download link when automatic updating fails.
- Automatic cleanup is disabled in public defaults to protect new installations.

### Important

The updater installs a downloaded JAR on the next server restart. Always back up the target world before enabling cleanup. The current cleanup engine can synchronously load chunks and may trigger Folia Watchdog warnings across large areas.

## 中文

WorldAreaReset 1.1.0 是首个公开双语版本，新增简体中文与英文模式、安全的公开默认配置、GitHub 更新检查、可选自动下载以及重新设计的启动横幅。

### 主要内容

- 通过 `language` 选择 `zh_CN` 或 `en_US`。
- 可使用英文默认或简体中文默认 Release JAR。
- 服务器启动时自动检查官方 GitHub Releases。
- 发现新版本后，将校验过的 JAR 下载至 Bukkit 更新目录。
- 自动更新失败时在后台显示 GitHub 手动下载地址。
- 公开默认配置关闭自动清理，保护首次安装的服务器。

### 重要说明

下载的新 JAR 会在下一次服务器重启时安装。启用清理前必须备份目标世界。当前清理引擎在大范围运行时可能同步加载区块并触发 Folia Watchdog 警告。
