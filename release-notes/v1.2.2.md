# WorldAreaReset v1.2.2

## English

WorldAreaReset 1.2.2 completes and widens the console startup banner so its right border remains aligned and clear of every field.

### Downloads

- English defaults: `WorldAreaReset-1.2.2-en.us.jar`
- Simplified Chinese defaults: `WorldAreaReset-1.2.2-zh.cn.jar`

Release automation uploads exactly these two files from `build/libs/` under their original names.

### Startup banner

- Expanded the banner interior from 58 to 64 terminal columns.
- Added the missing right-side `|` border to every metadata and privacy row.
- Uses the same color for both sides of the border.
- Ignores legacy color codes when calculating padding.
- Counts Chinese characters as double-width terminal columns for consistent bilingual alignment.
- Leaves clear spacing between the longest GitHub field and the right border.

### Compatibility and safety

- Tested and supported only on Paper/Folia 1.21.11 with Java 21.
- Automatic cleanup remains disabled in official defaults.
- Configuration values, comments, cleanup behavior, scheduling, updater behavior, and in-game messages are unchanged.
- Back up the target world before enabling cleanup.

## 中文

WorldAreaReset 1.2.2 补全并加宽服务器后台启动横幅，使右侧边框在所有字段之后保持对齐且不会遮挡文字。

### 下载

- 英文默认包：`WorldAreaReset-1.2.2-en.us.jar`
- 简体中文默认包：`WorldAreaReset-1.2.2-zh.cn.jar`

Release 自动化只会从 `build/libs/` 原名上传这两个文件。

### 启动横幅

- 将横幅内部宽度从 58 个终端列扩展为 64 个终端列。
- 为每一行元数据和隐私声明补上缺失的右侧 `|` 边框。
- 左右边框使用相同颜色。
- 计算留白时忽略旧式颜色码。
- 中文字符按双列终端宽度计算，使双语内容稳定对齐。
- 最长的 GitHub 地址与右侧边框之间保留清晰空隙。

### 兼容与安全

- 仅测试并支持 Paper/Folia 1.21.11 与 Java 21。
- 官方默认配置继续关闭自动清理。
- 配置值、注释、清理行为、排程、更新器行为与游戏内消息均未更改。
- 启用清理前必须备份目标世界。
