# WorldAreaReset v1.2.0

## English

WorldAreaReset 1.2.0 introduces immutable versioned filenames for both official language packages and a redesigned color-coded console startup experience.

### Downloads

- English defaults: `WorldAreaReset-1.2.0-en.us.jar`
- Simplified Chinese defaults: `WorldAreaReset-1.2.0-zh.cn.jar`

The package template is `WorldAreaReset-<version>-<language>.jar`. Release automation uploads these two files directly from `build/libs/` without renaming, relabeling, or adding another JAR.

### Console and updater

- The startup banner uses one consistent gold `WorldAreaReset` prefix on every line.
- Version, author, Paper/Folia 1.21.11 support, active language, GitHub URL, and the open-source privacy statement are shown with distinct colors.
- Update checking, current version, available version, manual download, download completion, disabled checks, and failures each use a clear status color.
- Automatic updates dynamically select `WorldAreaReset-<latest-version>-en.us.jar` or `WorldAreaReset-<latest-version>-zh.cn.jar` according to `language`.

### Compatibility and safety

- Tested and supported only on Paper/Folia 1.21.11 with Java 21.
- Automatic cleanup remains disabled in official defaults.
- Cleanup parameters, configuration comments, manual cleanup, countdown behavior, and terrain-cleanup logic are unchanged.
- Back up the target world before enabling cleanup.

## 中文

WorldAreaReset 1.2.0 为两个官方语言包加入不可变的版本化文件名，并重新设计带有状态颜色的后台启动体验。

### 下载

- 英文默认包：`WorldAreaReset-1.2.0-en.us.jar`
- 简体中文默认包：`WorldAreaReset-1.2.0-zh.cn.jar`

文件名模板为 `WorldAreaReset-<版本>-<语言>.jar`。Release 自动化会直接上传 `build/libs/` 中的这两个文件，禁止改名、改标签或加入其他 JAR。

### 后台与更新器

- 启动横幅的每一行都使用同一个金色 `WorldAreaReset` 前缀。
- 版本、作者、Paper/Folia 1.21.11 支持范围、当前语言、GitHub 地址及开源隐私声明分别着色显示。
- 检查更新、已是最新版、发现新版、手动下载、下载完成、更新关闭和更新失败均使用清晰的状态颜色。
- 自动更新器会按照 `language` 动态选择 `WorldAreaReset-<最新版本>-en.us.jar` 或 `WorldAreaReset-<最新版本>-zh.cn.jar`。

### 兼容与安全

- 仅测试并支持 Paper/Folia 1.21.11 与 Java 21。
- 官方默认配置继续关闭自动清理。
- 清理参数、配置注释、手动清理、倒计时行为及地形清理逻辑均未更改。
- 启用清理前必须备份目标世界。
