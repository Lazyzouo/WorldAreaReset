# WorldAreaReset 1.0.0

## English

- Publish a single `WorldAreaReset-1.0.0.jar`; the package starts with the English `config.yml` and includes the Chinese configuration template.
- Align player and console output with Kitloader-compatible MiniMessage parsing, legacy colors, fixed prefixes, separators, and status severity colors.
- Use configuration format 25 with hyphenated updater settings, flat updater messages, safe migration, and atomic backups.
- Require a SHA-256 release digest and enforce the 50 MiB automatic-update download limit.
- Preserve administrator settings and unknown custom keys while keeping destructive automatic cleanup disabled by default.

## 中文

- 只发布一个 `WorldAreaReset-1.0.0.jar`；安装后默认使用英文 `config.yml`，并在包内提供中文配置模板。
- 按照与 Kitloader 兼容的 MiniMessage 解析、Legacy 颜色、固定前缀、分割线和状态严重级别颜色统一玩家端与后台输出。
- 使用格式 25 配置，采用连字符更新参数、扁平更新消息、安全迁移和原子备份。
- 自动更新必须具备 SHA-256 发布摘要，并限制下载大小为 50 MiB。
- 迁移时保留管理员设置和未知自定义键，官方默认仍关闭具有破坏性的自动清理。
