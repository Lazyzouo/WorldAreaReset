# WorldAreaReset v1.2.5

## English

WorldAreaReset 1.2.5 prevents decorative divider rows from wrapping when multiline in-game messages use the configured plugin prefix.

### Downloads

- English defaults: `WorldAreaReset-1.2.5-en.us.jar`
- Simplified Chinese defaults: `WorldAreaReset-1.2.5-zh.cn.jar`

Release automation uploads exactly these two files from `build/libs/` under their original names.

### In-game divider formatting

- Decorative divider rows render without the configured plugin prefix, preserving their full available chat width.
- Content rows in the same multiline message continue to display the prefix.
- Divider recognition ignores legacy and hex formatting codes and supports the bundled `━ ... ✦ ... ━` pattern plus common ASCII and box-drawing separators.
- Bold styling and left alignment remain active for divider and content rows.
- Administrator configuration, language files, and message text are not rewritten.

### Release retention

- `v1.2.5` is the new permanent retention floor.
- GitHub Releases and tags for `v1.2.4` and earlier are removed only after `v1.2.5` passes CI, CodeQL, asset, and digest verification.
- `v1.2.5` and every later version will be retained.

### Compatibility and safety

- Tested and supported only on Paper/Folia 1.21.11 with Java 21.
- Automatic cleanup remains disabled in official defaults.
- Cleanup behavior, scheduling, updater behavior, and the console startup banner are unchanged.
- Back up the target world before enabling cleanup.

## 中文

WorldAreaReset 1.2.5 修复了多行游戏内消息使用插件前缀时，装饰分割线因占宽而折行的问题。

### 下载

- 英文默认包：`WorldAreaReset-1.2.5-en.us.jar`
- 简体中文默认包：`WorldAreaReset-1.2.5-zh.cn.jar`

Release 自动化只会从 `build/libs/` 原名上传这两个文件。

### 游戏内分割线格式

- 装饰分割线不再显示已配置的插件前缀，从而保留完整可用聊天宽度。
- 同一条多行消息中的正文行继续显示插件前缀。
- 分割线识别会忽略旧式与十六进制格式码，并支持内置的 `━ ... ✦ ... ━` 模板以及常见 ASCII 和框线分隔字符。
- 分割线与正文行继续应用粗体和左对齐。
- 不会改写管理员配置、语言文件或消息文本。

### 版本保留

- `v1.2.5` 是新的永久保留起点。
- 仅在 `v1.2.5` 通过 CI、CodeQL、附件及摘要校验后，删除 `v1.2.4` 与更早的 GitHub Release 和标签。
- `v1.2.5` 及以后发布的每个版本都会保留。

### 兼容与安全

- 仅测试并支持 Paper/Folia 1.21.11 与 Java 21。
- 官方默认配置继续关闭自动清理。
- 清理行为、排程、更新器行为及后台启动横幅均未更改。
- 启用清理前必须备份目标世界。
