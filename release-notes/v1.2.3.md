# WorldAreaReset v1.2.3

## English

WorldAreaReset 1.2.3 adds a structured bilingual identity section to the console startup banner.

### Downloads

- English defaults: `WorldAreaReset-1.2.3-en.us.jar`
- Simplified Chinese defaults: `WorldAreaReset-1.2.3-zh.cn.jar`

Release automation uploads exactly these two files from `build/libs/` under their original names.

### Startup banner

- Keeps the centered `WORLDAREARESET TERRAIN SERVICE v1.2.3` title.
- Adds the centered bilingual subtitle `PVP TERRAIN MAINTENANCE / PVP 地形维护`.
- Adds a full-width dashed separator before version, author, platform, language, project URL, and privacy fields.
- Retains the 64-column interior, complete right border, bilingual terminal-width alignment, colors, and GitHub spacing from 1.2.2.

### Compatibility and safety

- Tested and supported only on Paper/Folia 1.21.11 with Java 21.
- Automatic cleanup remains disabled in official defaults.
- Configuration, cleanup behavior, scheduling, updater behavior, and in-game messages are unchanged.
- Back up the target world before enabling cleanup.

## 中文

WorldAreaReset 1.2.3 为服务器后台启动横幅新增结构化的双语身份标题区。

### 下载

- 英文默认包：`WorldAreaReset-1.2.3-en.us.jar`
- 简体中文默认包：`WorldAreaReset-1.2.3-zh.cn.jar`

Release 自动化只会从 `build/libs/` 原名上传这两个文件。

### 启动横幅

- 保留居中的 `WORLDAREARESET TERRAIN SERVICE v1.2.3` 主标题。
- 新增居中的双语副标题 `PVP TERRAIN MAINTENANCE / PVP 地形维护`。
- 在版本、作者、平台、语言、项目地址和隐私字段之前新增整行虚线分隔线。
- 保留 1.2.2 的 64 列内部宽度、完整右边框、双语终端宽度对齐、颜色和 GitHub 地址留白。

### 兼容与安全

- 仅测试并支持 Paper/Folia 1.21.11 与 Java 21。
- 官方默认配置继续关闭自动清理。
- 配置、清理行为、排程、更新器行为与游戏内消息均未更改。
- 启用清理前必须备份目标世界。
