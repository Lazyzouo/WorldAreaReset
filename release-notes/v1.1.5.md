# WorldAreaReset v1.1.5

## English

WorldAreaReset 1.1.5 introduces official ready-to-use English and Simplified Chinese JAR packages and simplifies GitHub Release downloads.

### Release packages

- `WorldAreaReset-en.us.jar` includes the complete commented official English default configuration.
- `WorldAreaReset-zh.cn.jar` includes the complete commented official Simplified Chinese default configuration.
- Both JARs contain identical plugin code. Only the bundled official default configuration differs.
- Build verification compares each packaged `config.yml` byte-for-byte with its maintained source file, so comments and configuration content are not removed during packaging.
- Project-uploaded Release assets are limited to these two JARs. GitHub's automatically generated source archives remain available separately.

### Automatic updates

- `language: en_US` selects `WorldAreaReset-en.us.jar`.
- `language: zh_CN` selects `WorldAreaReset-zh.cn.jar`.
- The downloaded file is still installed through Bukkit's update directory on the next server restart.
- Existing server configuration remains in place during an automatic plugin update.

## 中文

WorldAreaReset 1.1.5 新增可直接使用的官方英文与简体中文 JAR，并精简 GitHub Release 下载资源。

### 发布包

- `WorldAreaReset-en.us.jar` 内置保留完整注释的官方英文默认配置。
- `WorldAreaReset-zh.cn.jar` 内置保留完整注释的官方简体中文默认配置。
- 两个 JAR 的插件代码完全相同，仅内置的官方默认配置不同。
- 构建校验会逐字节比较包内 `config.yml` 与维护中的源文件，确保打包过程不会删除注释或配置内容。
- 项目上传的 Release 附件仅保留这两个 JAR；GitHub 自动生成的源码压缩包仍会单独提供。

### 自动更新

- `language: en_US` 会选择 `WorldAreaReset-en.us.jar`。
- `language: zh_CN` 会选择 `WorldAreaReset-zh.cn.jar`。
- 下载文件仍会写入 Bukkit 更新目录，并在下一次服务器重启时安装。
- 自动更新插件时，服务器已有配置会继续保留。
