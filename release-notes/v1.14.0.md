# WorldAreaReset 1.14.0

## English

- Flatten the selected language into one editable `messages` section and remove generated language files.
- Remove retired `formatting`, `inline-replacements`, and root `gradient-colors` settings during format 23 migration.
- Use the fixed KitLoader five-color gradient, bold formatting, and `✧` divider for bundled messages.
- Display cleanup and restoration countdowns in the configured minutes, hours, or days unit.
- Publish one `WorldAreaReset-1.14.0.jar` containing the English default and Chinese configuration template.

## 中文

- 将当前语言扁平写入单一 `messages` 区域，并删除自动生成的语言文件。
- 格式 23 迁移时移除旧的 `formatting`、`inline-replacements` 和 root `gradient-colors` 设置。
- 所有默认消息使用 KitLoader 五色渐变、粗体格式和 `✧` 分割线。
- 清理与热恢复倒计时按配置的分钟、小时或天显示。
- 仅发布一个 `WorldAreaReset-1.14.0.jar`，内置英文默认配置和中文配置模板。
