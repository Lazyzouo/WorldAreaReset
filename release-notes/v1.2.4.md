# WorldAreaReset v1.2.4

## English

WorldAreaReset 1.2.4 makes every player-facing in-game message consistently left aligned.

### Downloads

- English defaults: `WorldAreaReset-1.2.4-en.us.jar`
- Simplified Chinese defaults: `WorldAreaReset-1.2.4-zh.cn.jar`

Release automation uploads exactly these two files from `build/libs/` under their original names.

### In-game text

- Removes leading whitespace independently from every displayed line, including Help entries, command feedback, countdown warnings, cleanup broadcasts, and completion messages.
- Preserves leading legacy color/style codes and hex colors while continuing to force bold styling after color and reset codes.
- Keeps the configured plugin prefix on every line of multiline broadcasts.
- Keeps divider rows as decoration, but no longer uses their `✦` characters as centering anchors.
- Does not rewrite administrator configuration or language files.

### Compatibility and safety

- Tested and supported only on Paper/Folia 1.21.11 with Java 21.
- Automatic cleanup remains disabled in official defaults.
- Message text, colors, cleanup behavior, scheduling, updater behavior, and the centered console startup banner are unchanged.
- Back up the target world before enabling cleanup.

## 中文

WorldAreaReset 1.2.4 将所有面向玩家的游戏内消息统一改为左对齐。

### 下载

- 英文默认包：`WorldAreaReset-1.2.4-en.us.jar`
- 简体中文默认包：`WorldAreaReset-1.2.4-zh.cn.jar`

Release 自动化只会从 `build/libs/` 原名上传这两个文件。

### 游戏内文本

- 逐行移除所有显示文本的行首空白，包括 Help 条目、指令反馈、清理倒计时、清理广播和完成消息。
- 保留行首旧式颜色/样式码与十六进制颜色码，并继续在颜色码和重置码之后强制应用粗体。
- 多行广播的每一行继续显示已配置的插件前缀。
- 分割线继续作为装饰，但其中的 `✦` 不再作为居中基准。
- 不会改写管理员配置或语言文件。

### 兼容与安全

- 仅测试并支持 Paper/Folia 1.21.11 与 Java 21。
- 官方默认配置继续关闭自动清理。
- 消息文本、颜色、清理行为、排程、更新器行为及居中的后台启动横幅均未更改。
- 启用清理前必须备份目标世界。
