# WorldAreaReset v1.1.3

## English

WorldAreaReset 1.1.3 publishes an official open-source and privacy assurance.

### Open source and privacy

- The complete project remains available under the MIT License for independent audit and local builds.
- The plugin contains no backdoor, telemetry, analytics, remote administration, hidden data collection, or server-data upload functionality.
- Plugin-created configuration, language, and update files remain on the administrator's server.
- Terrain, entity, player, world, configuration, credential, and log data are never sent to the project author.
- The only optional runtime network feature is the outbound official GitHub Release update check and JAR download.
- GitHub necessarily receives standard HTTPS connection metadata under its own policies; this is now stated explicitly.
- Set `updates.enabled: false` to disable all WorldAreaReset runtime network access.

The bilingual declaration is pinned at the top of the README and administrator guide. The complete statement is available in the repository's `PRIVACY.md`.

## 中文

WorldAreaReset 1.1.3 正式发布开源与隐私保证声明。

### 开源与隐私

- 完整项目继续以 MIT License 开源，可独立审查并在本地构建。
- 插件不含后门、遥测、统计分析、远程管理、隐藏数据收集或服务器资料上传功能。
- 插件创建的配置、语言和更新文件只保存在管理员自己的服务器上。
- 地形、实体、玩家、世界、配置、凭据和日志资料不会发送给项目作者。
- 唯一可选联网功能是向官方 GitHub Release 发起出站更新检查和 JAR 下载。
- GitHub 会依据其自身政策接收标准 HTTPS 连接元数据，声明中已明确说明这一点。
- 设置 `updates.enabled: false` 可完全关闭 WorldAreaReset 的运行时联网。

双语声明已置于 README 与管理员手册顶部，完整内容位于仓库的 `PRIVACY.md`。
