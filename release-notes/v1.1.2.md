# WorldAreaReset v1.1.2

## English

WorldAreaReset 1.1.2 is a documentation-only configuration update.

### Changes

- Added inline explanations for every parameter in the official Chinese and English configurations.
- Documented default values, accepted language values, time units, world naming, inclusive coordinate rules, Material naming, update dependencies, and restart behavior.
- Kept every YAML parameter value unchanged.
- Kept all messages, notifications, help menus, and plugin runtime logic unchanged.

### Compatibility

Tested and supported on Paper/Folia 1.21.11 with Java 21 or newer. Automatic cleanup remains disabled in the official defaults.

## 中文

WorldAreaReset 1.1.2 是仅补充配置说明的更新。

### 变更

- 为官方中英文配置中的每个参数增加行内说明。
- 补充默认值、语言可选值、时间单位、世界名称、包含边界的坐标规则、Material 命名、更新参数依赖及重启生效逻辑。
- 所有 YAML 参数值保持不变。
- 所有消息、通知、帮助菜单及插件运行逻辑保持不变。

### 兼容性

仅测试并支持 Java 21 或更高版本上的 Paper/Folia 1.21.11。官方默认配置仍关闭自动清理。
